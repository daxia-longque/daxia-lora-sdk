## 项目简介

本仓库提供大夏龙雀 **LoRa 二次开发系列模组**（如 DX-LR20-900M2S）的完整 SDK 开发环境。

支持用户基于 C/C++ 语言直接编写应用层代码，深度定制 LoRa 通信协议、功耗策略与业务逻辑，适用于对功耗、延迟或协议有特殊要求的工业级项目。

## SDK 目录结构

SDK 按功能模块划分，便于开发者快速定位：

| 文件夹名称 | 内容说明 | 适用阶段 |
| :--- | :--- | :--- |
| **00 开发环境IDE** | Keil/IAR/VSCode 工程模板及编译器配置指南 | 环境搭建 |
| **01 芯片技术手册** | SX1262/SX1278 等射频芯片原始数据手册 | 底层驱动开发 |
| **02 模块技术手册** | 模组规格书、引脚定义、电源管理说明 | 硬件设计 |
| **03 开发板技术手册** | 官方开发板原理图、PCB、调试接口说明 | 硬件调试 |
| **04 测试工具** | 串口助手、频谱分析仪配置脚本、自动化测试脚本 | 功能验证 |
| **05 硬件资料** | 原理图库、PCB封装库、天线匹配电路参考设计 | PCB Layout |
| **06 代码示例** | LoRaWAN Class A/C、点对点通信、低功耗休眠等完整示例 | 应用开发 |
| **07 参考链接** | Semtech 官方文档、LoRa Alliance 规范、社区论坛链接 | 深入学习 |
| **08 单片机例程** | 基于 STM32L4/ESP32-S3 的完整工程，含 Bootloader 与 OTA | 量产参考 |

## 快速开始 (Quick Start)

1. **环境搭建**：下载并安装 `04 测试工具` 中的烧录工具和串口助手。
2. **烧录程序**：打开 烧录工具, 通过工具将`06 代码示例` 中的文件 ，烧录至开发板。
3. **调试运行**：烧录完成后重启开发板，使用串口助手互发数据, 验证开发板功能。

## 二次开发注意事项

- LoRa 射频性能对 PCB 布局敏感，请务必严格遵守 `05 硬件资料` 中的 Layout 规范。
- 二次开发时请注意内存占用，避免堆栈溢出导致复位。
